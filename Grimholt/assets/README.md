# Grimholt: Arena – Assets

Alle hier abgelegten Assets gehören zum aktiven Multiplayer-Arena-Shooter.

## Branding

- `branding/grimholt_crest.svg` – Grimholt-Projektwappen.
- `branding/rifle_insignia.svg` – Waffen-/Rifle-Insignie.

## Arena

- `materials/arena_floor.svg` – nahtloses Bodenmuster für die Greybox-Arena.

Die Arena-Geometrie, Beleuchtung und übrigen Oberflächen werden derzeit direkt in
`scenes/shooter/arena.tscn` definiert. RPG-Terrain, Crafting-, Inventar- und
Weltumgebungs-Assets wurden aus dem Projekt entfernt.
